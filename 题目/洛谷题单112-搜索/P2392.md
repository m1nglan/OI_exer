## 题目描述

这次期末考试，kkksc03 需要考 $4$ 科。因此要开始刷习题集，每科都有一个习题集，分别有 $s_1,s_2,s_3,s_4$ 道题目，完成每道题目需要一些时间，可能不等（$A_1,A_2,\ldots,A_{s_1}$，$B_1,B_2,\ldots,B_{s_2}$，$C_1,C_2,\ldots,C_{s_3}$，$D_1,D_2,\ldots,D_{s_4}$）。


kkksc03 有一个能力，他的左右两个大脑可以同时计算 $2$ 道不同的题目，但是仅限于同一科。因此，kkksc03 必须一科一科的复习。


由于 kkksc03 还急着去处理洛谷的 bug，因此他希望尽快把事情做完，所以他希望知道能够完成复习的最短时间。

第 $5$ 行，为 $D_1,D_2,\ldots,D_{s_4}$ 共 $s_4$ 个数，意思均同上。

## 输出格式

先讲核心模型，再手动模拟一遍就通了：

**01 背包是啥**：有 n 个物品，第 i 个**重量 w[i]、价值 v[i]**，背包容量 C。每个物品**只能拿或不拿**（所以叫 0/1），求能装的最大总价值。

**状态**：`f[j]` = 容量为 j 时能装的最大价值

**转移**：对每个物品 i，枚举容量 j（**从大到小**）：
```cpp
f[j] = max(f[j], f[j - w[i]] + v[i]);
//       ↑不拿          ↑拿（腾出 w[i] 空间，加上价值）
```

**模板**：
```cpp
vector<int> f(C + 1, 0);          // 全部初始化为 0
for (int i = 0; i < n; i++)
    for (int j = C; j >= w[i]; j--)   // ★ 倒序！
        f[j] = max(f[j], f[j - w[i]] + v[i]);
cout << f[C];                     // 答案
```**为什么必须倒序（核心！）**：
- 倒序时 `f[j-w]` 还是"**没考虑当前物品**"时的值 → 每个物品最多用一次 ✓
- 正序的话 `f[j-w]` 可能已经被当前物品更新过 → 会重复拿同一个物品（那叫完全背包）✓

**手动模拟**（容量 5，物品：(1,1) (2,3) (3,4)）：
```
初始:      f = [0, 0, 0]     (容量0~5)
物品(1,1):  f = [0, 1, 1, 1]
物品(2,3):  f = [0, 1, 3, 4, 4]    ← j=5: max(1, f[3]+3=4)=4
物品(3,4):  f = [0, 1, 3, 4, 5, 7]    ← j=5: max(4, f[2]+4=7)=7
答案 f[5] = 7（拿物品2+3，重量 2+3=5，价值 3+4=7 ✓）
```

**你 P2392 用的变体**——「可行性背包」（不问最大价值，问**能不能凑出来**）：
```cpp
vector<bool> f(half + 1, false);
f[0] = true;
for (int w : t)
    for (int j = half; j >= w; j--)
        if (f[j - w]) f[j] = true;
```
`f[j] = true` 表示"这些题能凑出总时间 j"。找最大的可行 j（≤ sum/2）→ 该科时间 = sum − j ✓

**记住三句话**：
1. **01 背包倒序，完全背包正序**
2. 状态 `f[容量]`，转移考虑"拿 or 不拿"
3. 求最值用 `max`，求可行性用 `bool`（或 `||`）

**代码写法是对的** ✓（这就是重量=价值=s[i] 的 01 背包），就差 W！

**W = 该科所有题目时间总和的一半**：`W = sum / 2`

**为什么**：这题本质是"每科的题目分成两组（左脑/右脑），让**较大组尽量小**"——那等价于"让其中一组的和尽量接近总和的一半"。所以背包容量就取 `sum/2`（超过一半没意义，两组是对称的）。

**完整结构**（4 科各自跑一遍，重置 dp）：
```cpp
int ans = 0;
for (int k = 0; k < 4; k++) {
    // 读入这一科的 s[k] 道题，算 sum
    int sum = 0;
    for (int i = 0; i < s[k]; i++) { cin >> t[i]; sum += t[i]; }

    int W = sum / 2;                      // ← 背包容量
    vector<int> dp(W + 1, 0);             // ← 每科都要重置！

    for (int i = 0; i < s[k]; i++)
        for (int j = W; j >= t[i]; j--)
            dp[j] = max(dp[j], dp[j - t[i]] + t[i]);

    ans += sum - dp[W];                   // ← 该科用时
}
cout << ans;
```

**最后为啥是 `sum - dp[W]`**：
- `dp[W]` = 不超过一半能凑出的最大时间和（左脑的题）
- 右脑 = `sum - dp[W]`
- 该科用时 = max(两者) = `sum - dp[W]`（因为 dp[W] ≤ sum/2）

**样例验证**：4 科 → 5 + 4 + 6 + 5 = **20** ✓
（第2科 sum=7, W=3, 凑出 3 → 用时 7−3=4；第4科 sum=9, W=4, 凑出 4 → 用时 9−4=5）

**两个小提醒**：
1. **dp 每科都要清零**（vector 重新定义即清零）
2. **W 是每科自己的 sum/2**，不是全局一个数——4 科各算各的
