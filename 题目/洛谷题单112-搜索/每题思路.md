# 洛谷题单 112【算法1-7】搜索 — 每题思路

> 共 16 题：DFS 回溯 9 题 + BFS 最短路 7 题。搜索是本专题的核心，也是 CSP-J 机试 T2/T3 的高频考点。
> 通用套路：**DFS 想"状态 + 选择 + 剪枝"，BFS 想"状态 + 转移 + 判重"**。

---

## 一、DFS / 回溯类

### P1019 单词接龙（NOIP2000 提高组）
**思路**：预处理任意两个单词能接多长——a 的后缀与 b 的前缀最长重叠部分（重叠长度 < min(len(a), len(b))，不能完全包含）。
然后 DFS：从给定首字母的单词出发，每次尝试接一个"使用次数 < 2"且能接上的单词，累加长度取最大值。
- 关键：预处理龙长为 `len(a) - 重叠长度`；每个单词最多用两次（cnt 数组）
- 剪枝：重叠部分越长越好（贪心预处理即可，不需要在 DFS 里选）
- 复杂度：预处理 O(n²·L)，搜索 O(2ⁿ) 级别但实际很小

### P1032 字串变换（NOIP2002 提高组）
**思路**：BFS 求最少步数（每步把某子串按规则替换）。状态是字符串。
- 关键：**一个字符串里同一规则可能有多个匹配位置**，要枚举所有替换位置
- 用 `set<string>` 判重；步数超过 10 直接剪掉（题目要求 ≤10 步）
- 复杂度：状态数爆炸，靠步数上限 10 + set 剪枝；实在过不去用双向 BFS

### P1036 [NOIP2002 普及组] 选数
**思路**：DFS 组合枚举——从 n 个数中选 k 个（按递增下标防重复），求和后判素数。
- 关键：`dfs(now, cnt, sum)` 当前下标 / 已选个数 / 当前和；选够 k 个就判素数
- 素数判定：试除到 √sum 即可（sum ≤ 5×10⁷，用 `i*i<=sum` 防溢出）
- 复杂度：O(C(n,k)·√sum)

### P1101 单词方阵
**思路**：在 n×n 字母方阵里找 "yizhong"，方向固定（一旦选定方向必须一直走直线）。
- 关键：枚举每个起点（字母 'y'）+ 8 个方向，沿方向匹配全部 7 个字母，成功就标记
- 用 visited 标记输出，最后把未标记的字母输出为 `*`
- 复杂度：O(8n²·7)，非常小

### P1219 [USACO1.5] 八皇后
**思路**：经典 DFS 逐行放皇后，用三个数组判冲突：列 `col[]`、主对角线 `d1[i+j]`、副对角线 `d2[i-j+n]`。
- 关键：**输出前 3 个解**（按字典序，即逐行枚举天然有序）+ 总方案数
- 复杂度：O(n!)（n=13 时约 2.3×10⁶ 合法路径，能过）

### P1433 吃奶酪
**思路**：TSP 变体的**状压 DP**（比 DFS 剪枝稳）：`dp[S][i]` = 已走过集合 S、当前在点 i 的最短距离。
- 转移：`dp[S|1<<j][j] = min(dp[S][i] + dist(i,j))`
- 边界：`dp[1<<i][i] = dist(起点, i)`（起点是原点 (0,0)）
- 复杂度：O(2ⁿ·n²)，n ≤ 15 可以过（DFS + 最优性剪枝也能过）

### P1605 迷宫
**思路**：DFS 统计从起点到终点的路径数（有障碍、不能重复走）。
- 关键：`dfs(x,y)` 四方向扩展；到终点 ans++；回溯时恢复 visited
- 注意：题目说有障碍，输入按 (x, y) 给障碍坐标，注意行列对应关系
- 复杂度：指数级，但迷宫很小（n,m ≤ 5）

### P2036 [COCI2008/2009#2] PERKET
**思路**：DFS 枚举每种配料"选/不选"（2ⁿ 种），选了的算酸度乘积 − 苦度之和的绝对值，取最小。
- 关键：至少选一种配料（全不选要排除）；注意初始酸度是 1（乘法单位元）、苦度 0
- 剪枝：酸度乘积增长很快，可以提前剪（但 n ≤ 10 直接枚举够了）
- 复杂度：O(2ⁿ)

### P2404 自然数的拆分问题
**思路**：DFS 拆分 n 为若干正整数之和，**要求加数不降**（避免重复方案）。
- 关键：`dfs(remain, last, ...)` 枚举下一个加数 ≥ last 且 ≤ remain
- 输出格式：`n=a1+a2+...+ak`（k ≥ 2，即不能只有 n 自己）
- 复杂度：O(2ⁿ) 级别（n ≤ 8）

## 二、BFS / 最短路类

### P1135 奇怪的电梯
**思路**：BFS 最短路。第 i 层能到 i+Kᵢ 和 i−Kᵢ 层，问从 A 到 B 最少按几次。
- 关键：楼层是节点、按钮次数是边权（都是 1）→ 标准 BFS
- 注意越界判断（1 ≤ 目标层 ≤ N）；A == B 时答案是 0
- 复杂度：O(N)

### P1162 填涂颜色
**思路**：**反向思考**——被 1 包围的 0 无法从边界到达。所以从矩阵外圈所有 0 开始 BFS/DFS 染色（标记为外部），剩下的 0 就是被围住的 → 改成 2。
- 关键：在外层套一圈虚拟边界（或直接从四条边界上的 0 出发）
- 复杂度：O(n²)

### P1443 马的遍历
**思路**：BFS 求马从起点到棋盘每格的最少步数，走日字 8 个方向。
- 关键：棋盘是 n×m，用 `dis[][]` 数组存步数（初值 -1，未被访问）
- 输出格式：每个数宽 5 左对齐（`printf("%-5d")` 或 `cout << left << setw(5)`）
- 复杂度：O(nm)

### P1596 [USACO10OCT] Lake Counting S
**思路**：八连通块计数。遍历每个 'W'，没访问过就 DFS/BFS 把整个连通块标记掉，答案 +1。
- 关键：八方向（含斜角）
- 复杂度：O(nm)

### P1825 [USACO11OPEN] Corn Maze S
**思路**：BFS 带传送门。遇到大写字母传送门要瞬移到配对的另一个门。
- 关键：**传送门只记录"从哪来"**——走到门就直接移动到配对方（不额外计步，也不算作一次选择）
- 坑点：传送到对面后可能直接落在终点；传送门不能"停留"（必须立即传送）
- 复杂度：O(nm)

### P2392 kkksc03 考前临时抱佛脚
**思路**：4 个科目**互不影响**，逐科求最小时间再相加。单科问题 = 把题目分成两组，使两组时间和的最大值最小（等价于"子集和最接近总和的一半"）。
- 做法1：DFS 枚举每题放左/右，取 max(左,右) 的最小值（题数 ≤ 20，2²⁰ 会超时，需要剪枝）
- 做法2（推荐）：**背包/状压**：`f[j]` = 能否凑出左组时间和 j，找到最接近 sum/2 的 j → 该科时间 = max(j, sum−j)
- 复杂度：O(4·s·sum)（s 为单科题数）

### P2895 [USACO08FEB] Meteor Shower S
**思路**：BFS + 时间维度。先预处理每格"最早被砸时间" `t[][]`（流星及其四邻格，取 min）。
BFS 时：到达某格的时刻 < 该格被砸时间才能站；若走到 `t == INF`（永远不会被砸）的格子就可以停下。
- 关键：起点 (0,0) 可能一开始就被砸（t[0][0] == 0 时无解 → 输出 -1）
- 边界：坐标可能超过 300（流星砸到 300 之外），数组开到 305 以上
- 复杂度：O(nm)

## 三、搜索题通用技巧总结

| 技巧 | 说明 |
|---|---|
| **DFS 三要素** | 状态参数、终止条件、选择分支（+ 回溯恢复） |
| **剪枝** | 可行性剪枝（越界/冲突）、最优性剪枝（当前已比已知答案差）、记忆化 |
| **BFS 三要素** | 状态表示、转移方式、判重（vis 数组/set） |
| **判重数组** | BFS 必用；DFS 有时也能用（如棋盘类） |
| **多起点/多终点** | 反过来从终点搜，或加虚拟源点 |
| **时间维度** | 如果"能不能走"跟时刻有关（如流星），BFS 状态里带时间 |
| **连通块** | 遍历所有格子，未访问就搜一整块并计数 |
| **棋盘对角线判重** | 主对角线 `i+j`、副对角线 `i−j+N`（八皇后经典） |
| **指数搜索优化** | 状压 DP（吃奶酪）、双向 BFS（字串变换）、折半（考前抱佛脚） |

**复杂度速记**：DFS 一般是 O(状态数 × 分支数)（可能指数）；BFS 是 O(状态数)（每个状态只入队一次）。
